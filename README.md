# tinspire-cxii-python-suite
A compilation of custom python modules, software packages and games for the TI-Nspire CXII graphing calculator, these programs were all painstakingly developed from within the calculator's environment.

## How to Install on TI-Nspire CX II
1. Go to the [Releases](link-to-your-github-releases) page of this repository.
2. Download the `snake.tns` and `modules.tns` files from the latest version.
3. Plug your calculator into your computer via USB.
4. Open the [TI-Nspire CX II Connect](https://vernier.com) web utility or official TI software.
5. Drag and drop the downloaded `.tns` files onto your calculator.
